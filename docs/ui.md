# Interface
Primary flow: model preset → fixed/imported sample → run → inspect → history →
select two runs → compare → export. No fabricated charts or animated percentages.
Every unavailable metric is labelled. Detail text supports selection; numbers use
units and monospaced formatting. Dynamic system Forms/Lists support Dynamic Type
and VoiceOver. Existing Item CRUD remains accessible and its schema is retained.
The app prevents idle sleep during work; leaving active foreground or receiving a
memory warning cancels running work to avoid misleading background measurements.
